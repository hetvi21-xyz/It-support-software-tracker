# IT Support Software Tracker

A simple web-based tool for IT Support teams to track software installed on company computers.

## Features

- Add computer ID
- Add employee name
- Record software name and version
- Track software update status
- Search software records
- Delete records
- Data is saved using browser LocalStorage
- Simple dark and professional user interface

## Technologies Used

- HTML
- CSS
- JavaScript
- LocalStorage

## How to Use

1. Open the application in a web browser.
2. Enter the computer and employee details.
3. Enter the installed software and version.
4. Select the software status.
5. Click **Add Software** to save the record.
6. Use the search box to find software records.

## Project Purpose

This project demonstrates a basic IT Support solution for maintaining software installation records and identifying software that requires updates.
